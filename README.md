# My Investing — Home Assistant add-on

Add this repository in Home Assistant (**Settings → Apps → App store → ⋮ → Repositories**):

```
https://github.com/gabrieldutra/my-investing-addons
```

Then install **My Investing** and follow its Documentation tab. The image is
`ghcr.io/gabrieldutra/my-investing` (arm64 and amd64).
